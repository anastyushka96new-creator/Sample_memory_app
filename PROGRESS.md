## Готово и проверено
- Скелет с пятью слоями, границы слоёв проверяет ESLint. `npm run check` зелёный: 13 файлов, 114 тестов, сборка.
- Схема, миграции, целостность, каскад, поиск, фильтры, статистика, merge — с тестами.
- Загрузка с восстановлением, копии повреждённых данных, блокировка записи, баннеры ошибок.
- Debounce + flush на сворачивании, показ ошибки квоты.
- Экспорт/импорт (replace/merge, лимит 3 МБ, копия перед импортом).
- Проверено вручную в Chromium (собранный бандл): перезагрузка, поиск «й», flush на visibilitychange,
  повреждённый JSON → одна копия, нет ошибок в консоли.
- Проверено: `npx cap add android` и `cap sync` проходят, `androidScheme: https` попадает в конфиг.
